# DualLED Pro — runtime dependencies
#
# The app itself needs NOTHING here. Python 3.8+ and Tkinter (which ships with
# most Python installs; on Debian/Ubuntu: `sudo apt install python3-tk`).
# Controller access is the Windows HID driver through ctypes — no third-party
# package, which is the point: a pip package that failed to install after a
# PowerShell install is why the lightbar used to go dead.
#
# OPTIONAL — the hardware-accelerated 3D preview only.
# Without these the app still runs and still drives the lightbar; the preview
# falls back to the built-in Canvas drawing and says so in the log.
#
#   pip install PyOpenGL==3.1.10 pyopengltk==0.0.4
#
# They are deliberately NOT required here so that `pip install -r
# requirements.txt` failing can never again take the lightbar down with it.
